# Technical report decisions, 26 June 2026

**Historical decision record.** The [September proposal](202609071300-technical-report-plan-v2.md) replaces the old chapter plan and production checklist. Its proposed changes to these author decisions still require author review.

The June decisions were:

1. Keep the technical report aimed at researchers. Prepare a separate publication for families and educators.
2. Lead with one model per outcome and a summary table. Link the full catalogue from an appendix.
3. Use PDF as the canonical format, with print parity. Put technical depth in footnotes or appendices and keep code in the repository.
4. Give gradient boosting a short main-text chapter, with detailed rankings in an appendix.
5. Use plain bracketed causal-status labels that print clearly.

The original plan also chose equal-tailed intervals. The later [credible-interval decision](202607172359-credible-interval-standard.md) specifies the current inner 50% and outer 89% levels.

The removed checklist described a June worktree and an earlier model suite. For its exact contents, see [the original plan](https://github.com/dseinternational/language-reading-predictors/blob/b62fd6ce093c2cb81e5c842cf96ff11ffa6e4d95/notes/202606261500-technical-report-plan.md).
