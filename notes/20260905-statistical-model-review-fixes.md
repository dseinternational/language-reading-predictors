# Statistical model review fixes

The September review found seven errors in calculation, validation and trace reuse. These changes correct the code. Existing fitted results have not been replaced.

1. **Dose contrast.** The dose-response summary now moves each treated row from its period's attendance lower quartile to its upper quartile. Previously it added the quartile width to observed attendance. The posterior and prior summaries share the corrected endpoints. Other fitted terms, including child-mean attendance in the between/within model, stay fixed. DiD dose summaries retain their declared increase from observed attendance. The endpoint offset is bound to the declared `contrast_kind`: only the `one_sd_all_rows` kind starts at each row's own fitted dose, so `write_dose_slope_summary` refuses any other declared kind that arrives without `contrast_start_offset_std` rather than publishing a quartile label over observed-dose numbers.
2. **Constant matrix entries.** Convergence diagnostics exempt fixed entries only when the built distribution establishes a correlation Cholesky constraint. The distribution evidence is saved in the posterior's attributes for later checks. A zero upper entry in an ordinary matrix remains an assessability failure, even if its name resembles a Cholesky variable. A test over the representative family builds pins the positive case, so a family whose correlation factor is not a bare `LKJCorr` free variable fails there rather than silently losing the exemption. Traces written before this change carry no recorded constraint, so re-evaluating a stored fit reclassifies its Cholesky entries as genuine assessability failures; refit rather than re-reading those gates.
3. **Primary trace identity.** Reuse schema 2 fingerprints the computational graph, including operators, constants, ordered inputs, nested graphs, data values and coordinates. The previous human-readable model display abbreviated expressions and could miss a sign reversal. Generator state is excluded; the run contract separately binds sampling settings. Shared nodes contribute their dtype and shape to the structure hash and their contents to the design hash, so the two stay independent and a refusal still says whether the model code or only the data moved. A graph that cannot be fingerprinted cannot authorise reuse: `require_reuse_compatibility` refuses a missing structure or design hash outright, because two identical failure records would otherwise compare equal and pass.
4. **Secondary trace identity.** Each secondary fit records and verifies its own graph identity. Matching observations and a compatible primary fit cannot authorise a secondary posterior from a different prior or predictor design.
5. **Mediation integration.** Finite count mediator supports are summed exactly within each posterior draw. This includes period-stacked, parallel, sequential and off-floor mediator paths. Sequential mixed-arm cells retain the original independent coupling across arms. Normal mediators use successively finer Gauss-Hermite quadrature, with checks on counterfactual cells, effect intervals and directional probabilities. The published quantities decide convergence — effect quantiles and directional probabilities — with the absolute cell tolerance as a sufficient fast path rather than a third requirement, so a single tail draw with a large mediator slope times residual SD cannot abort an otherwise converged decomposition. Failure past that stops the decomposition. Posterior MCSE remains a separate measure of MCMC precision. The seed and replicate arguments are removed rather than silently ignored, so a caller passing them learns the estimand changed. The two-mediator enumeration evaluates each first-mediator mass, each conditional second-mediator mass and each arm's mediator-free outcome terms once instead of once per support cell.
6. **Gain-model LOO.** The factory now supplies the child map used to sum all transition likelihood contributions for a child. Leaving out one transition had retained its outcome as a later transition's baseline. The run plan and recipe describe the child holdout unit and the conditioning on supplied baseline predictors. Pareto diagnostics remain necessary before interpreting the importance-sampling estimate.
7. **K-fold persistence.** Each fold saves a separate trace and binds its training and held-out child indices, complete fold allocation and the K-fold settings that decide the partition to its provenance. `n_latent_draws` is deliberately excluded: it is spent scoring the held-out children after each fold is fitted, so binding it would force a full resample to change a number no fold uses. A reuse run loads those traces without sampling and refuses changed partitions.

## Verification and existing artefacts

Regression tests compare dose endpoints with explicit nonlinear calculations and count mediation with independent finite-support enumeration. A tightly concentrated synthetic posterior checks the small indirect effect that inner simulation previously obscured. Normal integration is checked against an independent adaptive integral. Other tests exercise a stuck ordinary matrix, changed primary and secondary models, child-level likelihood aggregation, and a complete K-fold save/reuse cycle with sampling forbidden during reuse.

Old reuse contracts and secondary provenance records lack the evidence required by the new checks and are refused. Do not add the new fields to old records by hand. Fresh fits must write the new contracts. Dose and mediation summaries and gain-model predictive scores need regeneration before publication under the corrected code. These numerical corrections do not change the study's identification assumptions or make its mediation decompositions identified causal effects.
