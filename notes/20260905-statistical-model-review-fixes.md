# Statistical model review fixes

The September review found seven errors in calculation, validation and trace reuse. These changes correct the code. Existing fitted results have not been replaced.

1. **Dose contrast.** The dose-response summary now moves each treated row from its period's attendance lower quartile to its upper quartile. Previously it added the quartile width to observed attendance. The posterior and prior summaries share the corrected endpoints. Other fitted terms, including child-mean attendance in the between/within model, stay fixed. DiD dose summaries retain their declared increase from observed attendance.
2. **Constant matrix entries.** Convergence diagnostics exempt fixed entries only when the built distribution establishes a correlation Cholesky constraint. The distribution evidence is saved in the posterior's attributes for later checks. A zero upper entry in an ordinary matrix remains an assessability failure, even if its name resembles a Cholesky variable.
3. **Primary trace identity.** Reuse schema 2 fingerprints the computational graph, including operators, constants, ordered inputs, nested graphs, data values and coordinates. The previous human-readable model display abbreviated expressions and could miss a sign reversal. Generator state is excluded; the run contract separately binds sampling settings. A graph that cannot be fingerprinted cannot authorise reuse.
4. **Secondary trace identity.** Each secondary fit records and verifies its own graph identity. Matching observations and a compatible primary fit cannot authorise a secondary posterior from a different prior or predictor design.
5. **Mediation integration.** Finite count mediator supports are summed exactly within each posterior draw. This includes period-stacked, parallel, sequential and off-floor mediator paths. Sequential mixed-arm cells retain the original independent coupling across arms. Normal mediators use successively finer Gauss-Hermite quadrature, with checks on counterfactual cells, effect intervals and directional probabilities. Failure stops the decomposition. Posterior MCSE remains a separate measure of MCMC precision. The old seed and replicate arguments remain accepted for archived callers but no longer affect these calculations.
6. **Gain-model LOO.** The factory now supplies the child map used to sum all transition likelihood contributions for a child. Leaving out one transition had retained its outcome as a later transition's baseline. The run plan and recipe describe the child holdout unit and the conditioning on supplied baseline predictors. Pareto diagnostics remain necessary before interpreting the importance-sampling estimate.
7. **K-fold persistence.** Each fold saves a separate trace and binds its training and held-out child indices, complete fold allocation and K-fold settings to its provenance. A reuse run loads those traces without sampling and refuses changed partitions.
