# Shared Quarto theme and fonts, 26 October 2026

Issue [#714](https://github.com/dseinternational/language-reading-predictors/issues/714) adopts DSE's Quarto design language. Its follow-up comment specifies [`tokens/2026.3.4`](https://github.com/dsegroup/apps-common/tree/tokens/2026.3.4), so this change uses that release, at commit `594ed7f74437cd253157fee1a5e860c11b639246`. The [Quarto appendix](https://github.com/dsegroup/apps-common/blob/tokens/2026.3.4/docs/design-language/quarto.md) defines the integration; the [release manifest](https://github.com/dsegroup/apps-common/blob/tokens/2026.3.4/dist/manifest.json) supplies the copied-file hashes and generator version 1.0.0.

The unmodified `dist/quarto/theme.scss` is copied to `docs/theme/dse.scss`. All 327 model templates and the book layer `project.scss` after it. That project file retains the scrolling box for long block equations and defines no fonts or token overrides. Both model report pipelines copy the two theme files beside their generated pages. The retired `_fonts.scss`, including its Google Fonts import, is removed. HTML now takes Noto Sans and Noto Sans Mono from DSE's CDN. MathML uses installed Noto Sans Math or the browser's maths font; the shared theme does not download a maths face.

The book's PDF uses LuaLaTeX and the release's seven TrueType faces: four Noto Sans faces, two Noto Sans Mono faces and Noto Sans Math. Each family retains its `OFL.txt`. Paths in the PDF configuration point to those copied files, so rendering does not require them to be installed as system fonts. Noto Sans Mono uses its natural size, replacing Monaspace Neon's previous scale of 0.75. A before/after render retained 33 pages; page review found readable code, equations, tables and footers without a need to reduce the new code face. The existing DOCX equation-font post-render step is unchanged.

`docs/theme/design-tokens.pin.json` records all 11 copied assets: the theme, seven font faces and three licences. Their bytes were verified against the release manifest at download time. Git preserves those bytes, and `scripts/check_design_token_pin.py` checks them offline in CI. The check rejects modified or missing assets and copied files omitted from the pin. As the upstream pinning guidance states, offline hashes alone do not prove that a manually edited pin matches its named release. Shared changes should be released upstream before updating these copies and their pin.

Validation rendered the complete book to HTML and PDF, and rendered isolated before/after copies of saved `lrp-rli-gbg-001` and `lrp-rli-itt-001` reports. All 53 model-report images loaded. At a 1,400-pixel browser width, their main figure widths changed from approximately 799 to 802 pixels; representative figures were inspected at that reading size. HTML text changes from the previous 17-pixel body with a 25.5-pixel line height to the shared theme's 16-pixel body with a 28-pixel line height. Desktop pages showed no horizontal page overflow. The PDF's embedded fonts confirm Noto Sans, Noto Sans Math and Noto Sans Mono; Monaspace Neon is absent. Scientific fits and figure artefacts were not regenerated.

The report, figure, pipeline-boundary and DOCX regression checks passed (565 tests), including real HTML renders for shared statistical-model prose. Ruff, mypy across 537 source files, the offline pin check and the include-order validator also passed. The validator checked all 277 statistical report templates. The three agent-instruction files remain identical.
